# Software Module Cover Letter and Contents

**Document ID:** D01-Module-Cover  
**Document version:** 1.0  
**Approval date:** 2026-05-01  
**Approved by:** R. Lindqvist, Regulatory Affairs Director  
**Software version covered:** 3.2.0  
**Applicant:** Halden Cardiac Systems GmbH (fictional)  
**Device:** CardioSense ARR Software Module

## 1. Purpose
Halden Cardiac Systems GmbH (fictional) submits the **software module** of the modular PMA P26xxxx for the CardioSense ARR Software Module, a Class III device software function that detects and classifies cardiac arrhythmias from a single-lead wearable ECG patch and presents episodes to clinicians.

**Software version proposed for approval: 3.2.0**
**Release build identifier: b1187**
**Module submission date: 2026-05-04**
**Documentation Level: Enhanced** (a failure or latent flaw could present a probability of serious injury or death; see D07 pre-control severity).
**IEC 62304 software safety class: C** (see D03 section 4).

## 2. Modular PMA shell
This module corresponds to shell entry M3 "Software" of the accepted PMA shell (FDA acceptance letter dated 2025-08-22). Bench and clinical modules (M1, M2) reference software version 3.1.4 for study CS-PS-02; differences to 3.2.0 are assessed in D12 section 5.
